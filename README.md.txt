# 🚀 Sistema de Control de Usuarios Fullstack

¡Bienvenido! Este proyecto es un sistema inteligente para manejar quién entra a una plataforma y qué permisos tiene.

## ✨ ¿Qué hace de especial a este proyecto?
* **🔐 Login Seguro:** Entra con tu usuario y contraseña de forma protegida.
* **👑 Panel de Administrador:** Si eres Admin, verás opciones que los usuarios normales no pueden ver.
* **🛡️ Roles y Permisos:** El sistema sabe quién eres y qué puedes hacer automáticamente.

## 🛠️ Tecnologías "Power"
* **Angular:** Para que la página se mueva rápido.
* **NestJS:** El cerebro del sistema que maneja la base de datos.
* **Base de Datos:** Donde guardamos a todos los usuarios de forma organizada.

## 🏠 Cómo usarlo en tu casa
1. Descarga este código (`git clone`).
2. Entra a `/backend`, instala con `npm install` y corre con `npm run start:dev`.
3. Entra a `/frontend`, instala con `npm install` y corre con `ng serve`.
